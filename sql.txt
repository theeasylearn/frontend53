How to insert a new row/record/tuple into table?
1st method 
--------------------------------
syntax 
insert into <tablename> values (value-1,value-2,value-3)

Example
--------------------------------
insert into category values (0,'T-SHIRT','t-shirt.jpg',NULL)
insert into category values (NULL,'JEANS','jeans.jpg',0)

2nd method 
--------------------
insert into <tablename> (field-1,field-2) values (value-1,value-2)

Example 
insert into category (title,photo) values ('laptop','laptop.jpg')
insert into category (title,photo) values ('mobile','mobile.jpg')

how to delete row from table?
----------------------------------------

to delete all row from table 
delete from <tablename>

Example
-----------------------
delete from category 


to delete specific rows (rows as per criteria)
delete from <tablename> where <relational_expression>

example 
------------------------------
delete category whose id is 60
delete from category where id=60

delete category whose id is in range of 60 to 70
delete from category where id>=60 and id<=70

delete category whose name is Bags or Fruits 
delete from category where title='Bags' or title='Fruits';


how to delete all rows and reset id to 0 
syntax 
truncate table <tablename>
example 
truncate table category 

how to update row?
-----------------------------------------------------------
update <tablename> set field-name = value, field-name-2 = value, field-name-3 = value, field-name-4 = value [where condition] 


update product table increase all product price by 0.99 and increase all product cost price by 5%

sql 
update products set price=price + 0.99, cost_price = cost_price + (cost_price * 5) /100

update product price to 100 rs, name to "Premium Notebook" brand to "navneet" of those product whose id is 1

update products set price=100,name="Premium Notebook",brand="navneet" where id = 1

how to fetch data from table?
---------------------------------------------------------
select *|column-list from tablename [where condition] [group by ] [having ] [order by ] [limit ]

display all fields and all rows from category tables 
select * from category 

display id and title of all rows from category table 
select id,title from category 

display all fields of 1st five rows 
select * from category limit 0,5

display all fields of next five rows 
select * from category limit 5,5

display all fields of next 20 rows 
select * from category limit 10,20

display all fields in name wise a to z order (ascending order )
select * from category order by title 

display all fields of 1st 20 rows in name wise z to a order (descending order )
select * from category order by title desc limit 0,20

display id, price and name of 10 most expensive product 
select id,name,price from products order by price desc limit 0,10

display id, price and name of 20 most cheap product 
select id,name,price from products order by price  limit 0,20
