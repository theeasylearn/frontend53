How to insert a new row/record/tuple into table?
1st method 
--------------------------------
syntax 
insert into <tablename> values (value-1,value-2,value-3)

Example
--------------------------------
insert into category values (0,'T-SHIRT','t-shirt.jpg',NULL)
insert into category values (NULL,'JEANS','jeans.jpg',0)

2nd method 
--------------------
insert into <tablename> (field-1,field-2) values (value-1,value-2)

Example 
insert into category (title,photo) values ('laptop','laptop.jpg')
insert into category (title,photo) values ('mobile','mobile.jpg')

how to delete row from table?
----------------------------------------

to delete all row from table 
delete from <tablename>

Example
-----------------------
delete from category 


to delete specific rows (rows as per criteria)
delete from <tablename> where <relational_expression>

example 
------------------------------
delete category whose id is 60
delete from category where id=60

delete category whose id is in range of 60 to 70
delete from category where id>=60 and id<=70

delete category whose name is Bags or Fruits 
delete from category where title='Bags' or title='Fruits';


how to delete all rows and reset id to 0 
syntax 
truncate table <tablename>
example 
truncate table category

-----------------------------------------------------------
update <tablename> set field-name = value, field-name-2 = value, field-name-3 = value, field-name-4 = value [where condition]

how to fetch data from table?
---------------------------------------------------------
select *|column-list from tablename [where condition] [group by ] [having ] [order by ] [limit ]

display all fields and all rows from category tables 
select * from category 

display id and title of all rows from category table 
select id,title from category 

display all fields of 1st five rows 
select * from category limit 0,5

display all fields of next five rows 
select * from category limit 5,5

display all fields of next 20 rows 
select * from category limit 10,20

display all fields in name wise a to z order (ascending order )
select * from category order by title 

display all fields of 1st 20 rows in name wise z to a order (descending order )
select * from category order by title desc limit 0,20

display id, price and name of 10 most expensive product 
select id,name,price from products order by price desc limit 0,10

display id, price and name of 20 most cheap product 
select id,name,price from products order by price  limit 0,20

aggregate function
-----------------------------------------------
function that work upon numeric field of table and always return single value is called aggregate function

sum()
it always return sum of numeric fields value in table 
example
findout total payment amount
select sum(amount) from payments 

avg()
it always return average value of numeric field in table

example
findout average payment amount 
select round(avg(amount),2) as 'average_payment' from payments; 

min()
it always return minimum value of numeric field in table

example
findout least(minimum) payment amount 
select min(amount) as minimum_payment from payments

max()
it always return maximum of value numeric field in table 

example
findout maximum payment amount 
select max(amount) as maximum_payment from payments  

count()
it count no of values in table 
example 
findout how many products company has 

select count(*) as 'total_products' from products;


findout how many customer company has 
select count(*) as no_of_customers from customers;

findout total no of orders company received
select count(*) as no_of_orders from orders;

Caution
---------------------------------
never use normal field along with aggregate function. otherwise it will  will provide misleading/incorrect output.
example 
findout customerName who has made minimum payment 

select customerNumber,min(amount) as minimum_payment from payments  

-------------------------------------
we can also where and other statement with aggregate function 

findout total payment amount paid by customerNumber 112

select sum(amount) from payments where customerNumber=112

findout no of payments, and average payment amount & total payment amount paid by customerNumber 114

select count(*), avg(amount), sum(amount) from payments where customerNumber=114


handling null 

findout no of payments, and average payment amount & total payment amount paid by customerNumber 113
select count(*) as no_of_payment , ifnull(avg(amount),0) as average_amount, ifnull(sum(amount),0) as 'sum_of_payment' from payments where customerNumber=113;


findout total payment, no of payment received in 2005
------------------------------------------------------------------------------
select sum(amount), count(*) from payments where paymentdate>='2005-01-01' and paymentdate<='2005-12-31'


findout no of cancelled orders 
-----------------------------------------------------------------------------
select count(*) as 'cancelled_orders' from orders where status='cancelled'


group by 
-------------------------
    group by clause is when we want to get sub total/grouping on repetitive fields value.
    group by clause should be used with aggregate functions only  
    field we use with group clause should be also displayed for meaningful output

findout no of orders cancelled, shipped, Disputed, in process etc
select count(*),status from orders group by status;

findout no of customers from each country, show them in descending order 
select count(*),country from customers group by country order by count(*) desc;

findout total payment amount paid by each customers 
select sum(amount),customerNumber from payments group by customerNumber;

findout total payment amount received in each calendar year 
select sum(amount),year(paymentDate) from payments group by year(paymentDate);

findout no of orders received from each customers and display them in no of order wise descending order 
select count(*),customerNumber from orders group by customerNumber order by count(*) desc 


display top 10 customer by payments 
select sum(amount),customerNumber from payments group by customerNumber order by sum(amount) desc  limit 0,10

display top 10 customer by orders count 
select count(*), customerNumber from orders group by customerNumber order by count(*) desc limit 0,10;

having 
--------------------------------------------------------------------------------
having clause is used to give condition on aggregate function's group by value. 
having clause is always used only when select statement has aggregate functions & group by clause. 

fetch customerNumber and total payment amount of those customer who have paid more then 500000 total payments 

select sum(amount), customerNumber from payments group by customerNumber having sum(amount)>500000

fetch country and no of customers from each country where customers count is above 10 and display them in descending order of count
select count(*),country from customers group by country having count(*)>10 order by count(*)

fetch no of order of each customers whose no of orders less then 5
select count(*),customerNumber from orders group by customerNumber having count(*)<5

how to fetch data from multiple tables. 

when we fetch data from multiple tables then it is called join operations between tables. there are many type of join we can use between tables 

Ram 
    A,B,C,D 

Shyam 
    C,D,E,F 

1) equi/Inner join 
    when we want to fetch data from multiple tables based upon common fields between tables it is called equi join. here it fetch only matching value from both tables 

2) Left join 
   we want to fetch data from two tables, we want to fetch all rows from left side table where we want to fetch only matching rows from right side tables based upon common field 

3) Right join 
   we want to fetch data from two tables, we want to fetch all rows from right side table and we want to fetch only matching rows from left side tables based upon common field 

4) full join 
    we want to fetch all rows from two tables without giving any condition on common fields at that time we use full join. it do cartisan product operation on both tables.
